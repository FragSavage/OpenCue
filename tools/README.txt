The ready-to-run Windows release includes the unmodified official ArtIsWar
LEQ Control Panel v1.0.0 in this folder. Download the release ZIP from the
repository's Releases page and extract it in full.

The optional portable tool is omitted from Git history because it exceeds
GitHub's normal file-size limit. Its GPL licence, notice and corresponding
source archive are retained under licenses/. The tool's release/source links
and verified SHA-256 are in licenses/LEQControlPanel-SOURCE.txt.
